# Advanced Food Delivery Time Estimator

This project uses real-world features to predict food delivery time using XGBoost and Random Forest models.

## Features
- Distance calculated using Haversine formula
- Traffic level, weather, and rider experience
- SHAP for model interpretability
- GridSearch for tuning

## 🔧 Tools
Python, scikit-learn, XGBoost, SHAP, Pandas

## 📊 Results
- MAE: 3.7972178131569434 mins
- R²: 0.74
